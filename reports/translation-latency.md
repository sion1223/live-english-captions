# 영어 번역 기능 검증

측정일: 2026-10-03 (한국 시간). 현재 PC, 저장된 Gemini 키, 격리된 Edge 프로필에서 확인했습니다.

## 0.4.4 모델 트랙 분리

- 이전 버전의 작업 큐 분리만으로는 음성 문장 번역과 화면 번역의 동일 모델 사용량 한도가 분리되지 않았습니다.
- 음성은 `gemini-3.5-transcribe-live`로 인식하고, 필요할 때만 `gemini-3.1-flash-lite`로 영어 번역합니다.
- 화면은 `gemini-3.5-flash-lite`만 사용하며 오류·재시도 상태도 화면 트랙에 한정합니다.
- 새 음성 번역 모델로 프랑스어 짧은 문장을 영어로 번역하는 API 요청 1회 성공.
- HTTP 응답 모의 검사: 화면 모델만 429/30초 대기 상태로 만들고, 짧은 영어 및 외국어 음성 문장은
  다른 모델 URL로 요청해 자막을 전달하는 것을 확인했습니다. Python 검사 17개 통과.
- 사용자 요청에 따라 이번 버전의 전체 브라우저 재검사는 생략했습니다. 아래 브라우저 측정은 0.4.3 기록입니다.
- 동일 프로젝트 전체 한도나 서비스 장애는 두 트랙에 영향을 줄 수 있습니다.

## 0.4.3 요청 분리 검증

- 화면 번역과 음성 문장 번역을 각각 전용 작업 큐에 배치하고 언어 판별도 별도 스레드로 분리했습니다.
- 영어 자막은 진행 중인 외국어 번역과 재시도를 기다리지 않습니다. 음성 번역의 고정 2.5초 대기를 제거했습니다.
- 동시 실행 브라우저 샘플: 화면 번역은 2.7초, 영어 인식 결과 수신 이후 전달까지 추가 지연은 21/4/5/1ms였습니다.
  이 숫자는 발화부터 표시까지 전체 지연이 아니며, 네트워크/API 응답 시간을 보장하지 않습니다.
- 차단된 화면 요청 중에도 음성 번역이 완료되고, 30초 재시도 대기 중에도 영어 자막이 전달되는 것을 모의 테스트로 확인했습니다.
  지연된 과거 번역이 최신 자막을 덮어쓰지 않는 검사도 통과했습니다.
- Python 단위 테스트 16개, JavaScript 단위 테스트 12개, 데스크톱/모바일 배치 및 실제 요청 시에만 JPEG를 만드는 검사 통과.
- 실제 Gemini 음성/화면 동시 실행, 확장 새로고침, 캡처 소스 변경, 실제 YouTube 음성 자막 브라우저 검사 통과.
- 같은 키와 번역 모델의 Google 측 사용량 한도는 공유합니다. 작업 큐 분리는 별도 API 할당량을 만드는 기능이 아닙니다.

## 초기 측정

| 측정 항목 | 결과 | 범위 |
|---|---:|---|
| 서버가 꺼진 상태에서 영상 버튼 클릭 → Gemini 음성 연결 | 3.19–3.21초 | 실제 브라우저, 2회 |
| 서버가 이미 켜진 상태에서 클릭 → 음성 연결 | 1.62–1.64초 | 실제 브라우저, 2회 |
| 짧은 한국어 문장 → 영어 텍스트 | 1.49초 | 번역 API만, 1회. 음성 인식 제외 |
| 영상의 한국어 문구 → 위치가 포함된 영어 결과 | 2.1–3.7초 | 브라우저 2회(2.1/2.3초), 직접 API 1회(3.71초) |

화면 문구는 합성 영상의 `게임을 시작합니다`였으며, 결과는 `Start the game`이었습니다.
화면은 기본 3초 간격으로 확인하므로 글자 등장부터 표시까지는 위 요청 시간에 0–3초가 더해집니다.
이 샘플 기준 대략 2–7초를 예상할 수 있지만, 실제 방송의 글자 크기/개수/장면 변화와 네트워크에 따라 달라집니다.
음성 인식부터 번역까지 전체 지연이나 다수 영상의 평균 지연을 측정한 결과는 아닙니다.

## 확인한 동작

- 브라우저 버튼에서 Native Messaging으로 서버를 자동 실행하고 Gemini 음성을 연결.
- 기존 API 키를 다시 입력하지 않고 사용. 설정창에는 키 값이 노출되지 않음.
- 합성 영상의 실제 음성을 인식하여 영어 자막을 표시.
- 영상 속 한국어를 영어로 번역하고 원문 옆에 배치.
- 1100px/390px 브라우저에서 라벨 범위와 글자 넘침 확인 및 스크린샷 검사.
- 화면 번역 켜기/끄기, 문구가 사라진 장면, 중지 처리.
- 9개 단위 테스트: 자동 언어 감지, 기존 방송 용어, 좌표 검증, 실행기 메시지 검증,
  영어 판별, 중간 결과 교체, 밀린 요청 제한, 최종 결과 대기, 요청 제한 이후 복구.

실제 YouTube의 DRM/CORS 제한과 Chrome 확장 아이콘을 통한 스크린샷 대체 경로는
이 합성 영상 검사에 포함되지 않습니다. 직접 프레임을 읽지 못하는 영상에서는 확장 아이콘에서 시작해야 합니다.

초기 연속 검증 중 Gemini HTTP 429가 한 번 발생했습니다. 당시 추가한 고정 요청 간격은 0.4.3에서 제거했고,
자동 대기/재시도는 유지하되 영어 자막 전달과 분리했습니다.
